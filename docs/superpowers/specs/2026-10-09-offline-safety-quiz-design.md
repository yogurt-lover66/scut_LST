# 离线实验室安全刷题扩展设计

> **已被取代（2026-10-09）。** 本目录已改为自动答题扩展，离线刷题功能及其页面（`quiz.html` / `quiz.js` / `quiz.css`）已移除。当前设计见 `2026-10-09-auto-answer-design.md`。本文仅作历史记录保留。

## 目标

在 `safetest` 目录创建一个可直接通过 Chrome“加载未打包的扩展程序”安装的离线刷题扩展。扩展使用随附的本地 `questions.json`，启动后不访问复旦网站、不跳转登录页面，也不向任何考试网页自动填写答案。

## 范围

包含：

- 从原项目复制本地题库到 `safetest/asset/questions.json`。
- 提供扩展弹窗入口和刷题页面。
- 支持随机抽题、上一题、下一题、提交当前答案、查看正确答案和得分。
- 支持重新开始一轮练习。
- 对题库格式和空题库进行清晰的错误提示。

不包含：

- 访问或匹配任何学校的考试网站。
- 自动跳转登录页面。
- 自动点击、自动选项或提交正式考试。
- 修改原项目。

## 结构与数据流

扩展采用 Manifest V3，只有 `storage` 权限，用于保存当前练习进度；不声明任何网站访问权限。

`popup.html` 提供启动按钮和简要状态。点击开始后打开扩展内部的 `quiz.html`。`quiz.js` 使用 `fetch(chrome.runtime.getURL("asset/questions.json"))` 读取题库，校验每题包含 `stem`、`answers` 和非空 `correct_answers`，随后在内存中维护当前轮次状态。

每道题显示题干和选项。单选题使用单选控件，多选题使用复选框；点击“提交答案”后才显示正确答案和本题结果。只有答案集合完全一致时计为正确。用户可以继续下一题或重新开始，最终显示答对数量和百分比。

## 错误处理

- 题库文件读取失败时显示“无法加载本地题库”。
- 题库不是数组、题目字段缺失或没有有效答案时显示“题库格式错误”。
- 空题库时显示“题库为空”。
- 未选择答案时不计分，并提示先选择选项。

## 验证

使用 Node 内置测试运行题库校验和计分逻辑，覆盖：有效题目、缺失字段、单选正确/错误、多选集合匹配、空答案和空题库。手动检查扩展目录不含复旦域名、外部 URL 或网站权限，并验证 Chrome 能加载 `manifest.json`。
