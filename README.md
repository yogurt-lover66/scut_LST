# scut_LST

华南理工大学实验室安全考试辅助 Chrome 扩展。打开试卷后，扩展根据本地题库匹配并勾选答案，由你核对后手动提交。

## 下载与安装

1. 在 [GitHub 仓库](https://github.com/yogurt-lover66/scut_LST) 点击 **Code → Download ZIP**，下载并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，开启右上角的 **开发者模式**。
3. 点击 **加载未打包的扩展程序**，选择解压后直接包含 `manifest.json` 的文件夹。
4. 将 **华工 SafeTest 自动答题** 固定到浏览器工具栏。

无需安装 Python 或其他运行环境。

## 使用

1. 自行登录 [华工实验室安全综合管理系统](https://zhsys.sb.scut.edu.cn/)。
2. 打开要作答的试卷，点击扩展中的 **开始自动答题**。
3. 查看网页右上角的进度，等待答题完成。
4. 核对答案，自行补答跳过的题目，然后手动提交试卷。

也可以先点击扩展，再在 10 分钟内打开试卷，扩展会等待试卷加载。

## 注意事项

- 扩展不会自动交卷；平台倒计时结束时可能自动交卷，请留意剩余时间。
- 题库匹配可能有误，使用后请自行核对答案。
- 未匹配或无法可靠确定答案的题目会跳过，需要自行作答。
- 账号和密码由学校登录页面处理，扩展不读取、不保存。
- 题库和答题内容在本地处理，反馈包也只保存到本地。
- 请遵守学校和考试平台的使用规定。

## 问题反馈与建议

答题完成后，点击右上角面板中的 **下载反馈包 ZIP**，将下载的 ZIP 文件作为邮件附件发送到 **[2744481242@qq.com](mailto:2744481242@qq.com)**，由作者排查问题、补充题库和完善扩展。

反馈包包含本轮题目、答题明细和反馈说明；有跳过题时，还会包含跳过题文件。若知道正确答案，可以解压后填写跳过题中的答案位置，再重新打包发送。不确定的答案请留空。

请在邮件中描述遇到的问题，注明需要修正的题目；有功能建议也欢迎直接发邮件联系。发送前可先查看附件内容，勿添加姓名、学号、账号或密码等个人信息。

面板中的 **邮件联系作者** 可以打开默认邮件应用，ZIP 附件需要手动添加；也可以直接打开自己的邮箱发送。

## 更新扩展

重新下载并解压最新版本，然后打开 `chrome://extensions/`，重新加载新的文件夹，或替换原文件夹内容后点击扩展卡片上的刷新按钮。最后刷新考试页面以加载新版本。
