# 华工 SafeTest 自动答题

华南理工大学实验室安全考试（`zhsys.sb.scut.edu.cn`）的 Chrome 扩展：进入试卷后按本地题库自动勾选答案，**永不自动交卷**，由你核对后手动提交。

## 最短使用流程

1. 加载本目录为 Chrome 未打包扩展。
2. 自行登录实验室安全综合管理系统。
3. 打开要作答的试卷，点击扩展中的 **开始自动答题**。
4. 核对答案后手动提交。

## 一、安装

1. 在 Chrome 地址栏输入 `chrome://extensions/` 并打开。
2. 开启页面右上角的 **开发者模式**。
3. 点击 **加载未打包的扩展程序**，选择本目录（直接包含 `manifest.json` 的那一层）。
4. 把 **华工 SafeTest 自动答题** 固定到工具栏。

```text
safetest/
├── manifest.json
├── extension/                  # content.js / popup.html / popup.js
├── asset/questions.json        # 题库，由 tools/build_bank.py 生成
└── tools/                      # 题库维护脚本（build_bank / import_* / export_skipped），光用扩展不需要碰（见 tools/README.md）
```

## 二、自动答题

1. 登录平台，打开考试列表（`https://zhsys.sb.scut.edu.cn/#/home/exam/index`）。
2. 点开要作答的试卷，再点击扩展中的 **开始自动答题**。
3. 网页右上角会出现状态面板，显示进度、已作答/跳过题数和匹配度。
4. 出现绿色完成提示后核对答案，手动提交。

如果先点扩展、后打开试卷也可以：扩展会等待最多 10 分钟，你在平台里打开试卷后自动开始。

> 页面在扩展安装或重载**之前**就打开时，旧的内容脚本已被回收。扩展会自动补注入一次；若补注入也失败，会提示你刷新页面——**此时它不会跳转**，避免把正在看的试卷冲掉。

**跳过的题目保持空白**，需要你自己作答。状态面板和控制台（F12）都会说明跳过原因（题库里没有，或有两道很像的题不敢确定）。

## 三、答完之后

答题跑完，右上角面板上有三个按钮：

| 按钮 | 内容 | 用途 |
|---|---|---|
| **下载跳过题（N 题）.txt** | 只含没答出来的题，答案位留空 | 自己作答；填完可以直接补进题库（有跳过时才出现） |
| **下载题目（给大模型）.txt** | 全部题目的题干和选项 | 贴给大模型作答 |
| **下载答题明细.json** | 全部题目 + 扩展实际选了什么 + 匹配度 + 跳过原因 | 复盘、补题库 |

拿大模型的回答（形如 `1.B  2.正确  3.AC`）跟扩展的答案比对：

```bash
python3 tools/compare_answers.py 答题明细.json 大模型答案.txt

# 如果还有真实答案（例如交卷后平台显示的），可以算真正的正确率
python3 tools/compare_answers.py 答题明细.json 大模型答案.txt 标准答案.txt
```

不加标准答案时，脚本只能报告**扩展与大模型的一致率**——一致不等于正确，两边可能一起错。

### 把没答出来的题补进题库（可选）

面板上的 **下载跳过题（N 题）.txt** 就是为这件事准备的——它导出的格式直接就是导入脚本认识的格式，不需要任何转换：

1. 点面板上的 **下载跳过题**，把文件放进 `zida/` 目录。
2. 在每题的 `**答案：**` 后填答案：单选 `B。`、多选 `A,B,D。`、判断 `错。`
   （没填答案的题会被自动忽略，可以分几次填、不用一次做完。）
3. 导入并重建题库：

```bash
python3 tools/import_paper_answers.py
python3 tools/build_bank.py
```

忘了在面板上点下载也没关系：`python3 tools/export_skipped.py` 会扫描 `zida/` 里的答题明细，把没命中的题重新导出成 `zida/待补题目.txt`，格式同上。

题库的转换方式、导入脚本的规则和自查脚本见 [tools/README.md](tools/README.md)。

## 四、它是怎么保证不答错的

题库里存在「一字之差、答案相反」的题，例如：

- `实验中溅入口中已下咽的强酸…` 对 `…强碱…`
- `压力表指示的压力值为绝对压力。`（错）对 `…相对压力。`（对）
- `以下几种气体中，最毒的气体为` 对 `…有毒的气体为`

这些题两两相似度最高到 **0.96**，光靠"相似度超过 0.9 就算匹配"必然出错。因此扩展要求**最佳匹配既达到阈值 0.92，又比次佳匹配高出至少 0.02**，否则整题跳过。

另外两条判据同样是原则性的，不是放宽：

- **按题型分池匹配**。页面上的题型（单选/多选/判断）是确定已知的，所以只让题目在同题型内竞争，跨题型条目不会互相干扰。
- **次优解答案相同就采纳**。题库里存在只差一个字的近义题干（例如"…移到通风良好的环境…"与"…环境中…"），答案完全一样。这种情况选哪个结果都一样，不该因为间距小就跳过。

全库校验结果：**2776 道题全部可作答**；39 组"相似但答案不同"的危险题对，双向 78 次呈现**零选错**；混合题干正确判为跳过。

选项一律**按文本匹配**而不是按字母，所以即使试卷打乱选项顺序也能选对。

## 五、边界

- 扩展只申请访问 `zhsys.sb.scut.edu.cn`。
- 账号密码由学校登录页面处理，扩展不读取、不保存。
- 题库保存在本地，不上传任何答题内容。
- 题干匹配不可靠时跳过，不猜测。
- 自动运行标记 10 分钟后失效。
- **代码中没有任何点击"提交试卷"的能力**，交卷始终由你手动完成。

## 六、常见问题

### 提示"题库未匹配"

该题不在题库里，需要自己作答。想让它下次能自动答，按上面「把没答出来的题补进题库」补一条即可。

### 提示"题库中有相近题，无法确定"

匹配到两道很像的题，扩展拒绝猜测。核对后手动作答即可。

### 多选题答错了或漏选

多选题的正确项必须全部出现在页面上才会作答；只要有一个正确项在页面上找不到，整题跳过而不是部分勾选。

### 打开试卷后没有任何反应

确认地址栏域名是 `zhsys.sb.scut.edu.cn`。扩展只在该域名下工作。

### 会不会自动交卷

不会。扩展只勾选选项，不碰提交按钮。另外注意**平台自身有倒计时，到点会由平台自动交卷**，请留意剩余时间。
